Task Number 1 -> What do you understand by Big O Notation?

Big O Notation is used to measure the performance of an algorithm. It tells us how the execution time or memory usage increases as the input size increases. It helps us compare different algorithms and choose the efficient one.

Task Number 2 -> What are Arrays? How many types of Arrays?

An array is a collection of elements of the same data type stored in continuous memory locations. Each element is accessed using its index.

There are mainly two types of arrays in Java:

a -> One Dimensional Array (1D Array)

b -> Two Dimensional Array (2D Array)

Java also supports multidimensional arrays like 3D arrays, but 1D and 2D are the most commonly used.

Task Number 3 -> What do you understand about Strings in Java?

A String in Java is a sequence of characters. It is used to store text like names, addresses, or messages. Strings in Java are immutable, which means once a string is created, its value cannot be changed.

Task Number 6 -> Declare static and normal variables and increment both. What do you observe?
class Demo {

    static int a = 10;
    int b = 10;

    void increment() {
        a++;
        b++;
        System.out.println("Static = " + a);
        System.out.println("Normal = " + b);
    }

    public static void main(String[] args) {
        Demo d1 = new Demo();
        Demo d2 = new Demo();

        d1.increment();
        d2.increment();
    }
}

Observation ->

Static variable is shared by all objects, so its value keeps increasing.

Normal variable belongs to each object separately, so every object has its own copy.

Task Number 12 -> What are Access Modifiers in Java?

Access modifiers decide from where a class, variable, method, or constructor can be accessed.

There are four access modifiers in Java:

a -> Public : Can be accessed from anywhere in the project.

b -> Private : Can be accessed only inside the same class.

c -> Protected : Can be accessed within the same package and by subclasses in other packages.

d -> Default : If no modifier is written, it is called default access. It can be accessed only within the same package.

Task Number 14 -> Show the difference between break and continue.
public class Main {

    public static void main(String[] args) {

        System.out.println("Using Break");

        for(int i = 1; i <= 5; i++) {
            if(i == 3)
                break;

            System.out.println(i);
        }

        System.out.println("Using Continue");

        for(int i = 1; i <= 5; i++) {
            if(i == 3)
                continue;

            System.out.println(i);
        }

    }
}

Observation ->

Break stops the loop completely when the condition is met.

Continue skips the current iteration and continues with the next iteration.
