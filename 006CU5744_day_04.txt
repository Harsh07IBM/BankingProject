WAP to display the functionality of Method Overloading

Method overloading means creating multiple methods with the same name but different parameters.

package org.example;

class MathOperation {

    int multiply(int a, int b) {
        return a * b;
    }

    int multiply(int a, int b, int c) {
        return a * b * c;
    }

    double multiply(double a, double b) {
        return a * b;
    }
}

public class Day4_MethodOverloading {

    public static void main(String[] args) {

        MathOperation operation = new MathOperation();

        System.out.println(operation.multiply(5, 4));
        System.out.println(operation.multiply(2, 3, 4));
        System.out.println(operation.multiply(2.5, 4.0));
    }
}

20
24
10.0

Write a brief history of Java

Java was developed by James Gosling and his team at Sun Microsystems.

The development of Java started in 1991. At first, the project was named Oak. Later, the name was changed to Java.

In 2010, Oracle acquired Sun Microsystems. After that, Oracle became responsible for the development and maintenance of Java.

Task 4:
WAP to show how custom defined LinkedList works

package org.example;

public class Day4_MyLinkedList {

    Item first;

    static class Item {
        int value;
        Item nextItem;

        Item(int value) {
            this.value = value;
            this.nextItem = null;
        }
    }

    public void addItem(int value) {

        Item newItem = new Item(value);

        if (first == null) {
            first = newItem;
            return;
        }

        Item currentItem = first;

        while (currentItem.nextItem != null) {
            currentItem = currentItem.nextItem;
        }

        currentItem.nextItem = newItem;
    }

    public void showItems() {

        Item currentItem = first;

        System.out.print("My Linked List: ");

        while (currentItem != null) {
            System.out.print(currentItem.value + " -> ");
            currentItem = currentItem.nextItem;
        }

        System.out.println("null");
    }

    public static void main(String[] args) {

        Day4_MyLinkedList numbers = new Day4_MyLinkedList();

        numbers.addItem(100);
        numbers.addItem(200);
        numbers.addItem(300);

        numbers.showItems();
    }
}

Output:

My Linked List: 100 -> 200 -> 300 -> null

Task 10:
What are the advantages and disadvantages of Encapsulation?

Advantages:

It provides data hiding.
It protects the internal data of a class.
We can control access to variables using getters and setters.
We can add validation before changing the data.
It makes the code easier to maintain.
It improves the security of the data.

Disadvantages:

It increases the amount of code because we need getters and setters.
It can make simple programs more lengthy.
It may add a small amount of overhead due to method calls.

Task 12:
What is Autoboxing and Auto-unboxing?

Autoboxing means automatically converting a primitive data type into its corresponding wrapper class object.

Example:

int number = 50;

Integer value = number;

Here, int is automatically converted into Integer.

Auto-unboxing means automatically converting a wrapper class object into its corresponding primitive data type.

Example:

Integer value = 50;

int number = value;

Here, Integer is automatically converted into int.

In simple words:

Autoboxing:
Primitive → Wrapper Object

Auto-unboxing:
Wrapper Object → Primitive

Difference between Level and Depth

Level represents the position of a node in a tree.

Depth represents the number of edges from the root node to a particular node.

Example:

          10          Level 0
         /  \
        20   30        Level 1
       / \
      40  50           Level 2

Depth of 10 = 0

Depth of 20 = 1

Depth of 40 = 2

Note: Some books consider the root as Level 1 instead of Level 0.

Multithreading

Implementing Runnable Interface

package org.example;

class WorkerTask implements Runnable {

    private String workerName;

    WorkerTask(String name) {
        workerName = name;
        System.out.println("Creating " + workerName);
    }

    @Override
    public void run() {

        System.out.println("Running " + workerName);

        try {

            for (int count = 3; count >= 1; count--) {

                System.out.println(
                        workerName + " : " + count
                );

                Thread.sleep(100);
            }

        } catch (InterruptedException e) {

            System.out.println(
                    workerName + " was interrupted"
            );
        }

        System.out.println(
                workerName + " has finished"
        );
    }
}

public class Day4_RunnableThread {

    public static void main(String[] args) {

        WorkerTask taskOne =
                new WorkerTask("Worker-One");

        WorkerTask taskTwo =
                new WorkerTask("Worker-Two");

        Thread firstThread =
                new Thread(taskOne);

        Thread secondThread =
                new Thread(taskTwo);

        firstThread.start();
        secondThread.start();
    }
}

WAP to create a Doubly Linked List

package org.example;

public class Day4_DoublyLinkedList {

    Node start;

    static class Node {

        int number;
        Node previous;
        Node next;

        Node(int number) {
            this.number = number;
        }
    }

    public void add(int number) {

        Node newNode = new Node(number);

        if (start == null) {
            start = newNode;
            return;
        }

        Node current = start;

        while (current.next != null) {
            current = current.next;
        }

        current.next = newNode;
        newNode.previous = current;
    }

    public void display() {

        Node current = start;

        while (current != null) {

            System.out.print(current.number + " <-> ");

            current = current.next;
        }

        System.out.println("null");
    }

    public static void main(String[] args) {

        Day4_DoublyLinkedList numbers =
                new Day4_DoublyLinkedList();

        numbers.add(10);
        numbers.add(20);
        numbers.add(30);
        numbers.add(40);

        numbers.display();
    }
}

Output:

10 <-> 20 <-> 30 <-> 40 <-> null

WAP to create a Circular Linked List

package org.example;

public class Day4_CircularLinkedList {

    Node firstNode;

    static class Node {

        int number;
        Node next;

        Node(int number) {
            this.number = number;
        }
    }

    public void add(int number) {

        Node newNode = new Node(number);

        if (firstNode == null) {

            firstNode = newNode;
            newNode.next = firstNode;

        } else {

            Node current = firstNode;

            while (current.next != firstNode) {
                current = current.next;
            }

            current.next = newNode;
            newNode.next = firstNode;
        }
    }

    public void display() {

        if (firstNode == null) {
            return;
        }

        Node current = firstNode;

        do {

            System.out.print(current.number + " -> ");

            current = current.next;

        } while (current != firstNode);

        System.out.println("(back to first node)");
    }

    public static void main(String[] args) {

        Day4_CircularLinkedList numbers =
                new Day4_CircularLinkedList();

        numbers.add(10);
        numbers.add(20);
        numbers.add(30);
        numbers.add(40);

        numbers.display();
    }
}

Output:

10 -> 20 -> 30 -> 40 -> (back to first node)
